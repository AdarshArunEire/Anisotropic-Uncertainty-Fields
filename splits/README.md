# Splits

`atlas_splits.tsv`: train / val / test for all 1,938 ATLAS entries
(2024-11-18 release), generated by
`src/auf/splits/atlas.py`.

- Grouping: connected components of entries linked by shared ECOD H-groups
  (homology level, stricter than 30% sequence identity).
- The one component with > 5% of entries (399 entries, chained superfamilies)
  is in train whole; other components are hash-assigned (seed
  `auf-splits-v1`) to reach 60 / 20 / 20 overall.
- Fixed before any Phase A result. Do not regenerate with a different seed.

Anything fitted is fitted on train, selected on val, and reported on test.
